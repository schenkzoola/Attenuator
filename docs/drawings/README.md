# Drawings

The drawings in the docs are generated by three scripts. They use only the Python standard library.

| Script | Makes | From |
|--------|-------|------|
| [`make_panel_svg.py`](make_panel_svg.py) | `panel.svg`, used in the manual, and `panel-plain.svg`, the panel without captions, used on packaging labels | The faceplate KiCad file |
| [`make_assembly_svgs.py`](make_assembly_svgs.py) | `assembly-*.svg`, used in the assembly guide | The main PCB KiCad file |
| [`make_patch_svgs.py`](make_patch_svgs.py) | `patch-*.svg`, the patch examples in the manual | The faceplate KiCad file |

## Panel drawing

The panel drawing in the [user manual](../manual.md) ([`../images/panel.svg`](../images/panel.svg)) is generated from the KiCad faceplate file, [`PassiveAttenuatorFaceplate.kicad_pcb`](../../PassiveAttenuatorFaceplate/PassiveAttenuatorFaceplate.kicad_pcb).

After changing the faceplate in KiCad, run this from anywhere in the repo:

```sh
python3 docs/drawings/make_panel_svg.py
```

### What it reads

| From the KiCad file | Used for |
|---------------------|----------|
| `Edge.Cuts` lines | Panel outline |
| Mounting-hole footprints and their drill sizes | Jacks (Ø6.0), the knobs (Ø7.0) and the rack screw holes |
| `F.SilkS` lines and text | The input boxes, the divider line and the labels |
| `F.SilkS` zones | The solid boxes behind the outputs |

The script tells holes apart by drill size, so if you change a hole size, update `JACK` and `POT` at the top of the script. The knobs are drawn by the script, and the "Level", "In" and "Out" captions are added by the script, not read from KiCad.

## Assembly drawings

After changing the main PCB in KiCad, run:

```sh
python3 docs/drawings/make_assembly_svgs.py
```

| Drawing | How it's made |
|---------|---------------|
| `assembly-1-parts.svg` | Front board view, drawn from the board outline, pads and front silkscreen in the PCB file |
| `assembly-2-faceplate.svg` | Side diagram. The part positions along the board come from the PCB file, and the heights are approximate. |
| `assembly-3-solder.svg` | Back board view, drawn from the PCB file |

The side view assumes the faceplate sits 12.5 mm further up than the PCB, matching the two KiCad files. If you move the parts on either board, update `OFFSET` near the top of the figures section.

## Patch examples

The patch drawings reuse the panel drawing and add module boxes and cables. Each example is a short function in the script, for example:

```python
def tame(data):
    p = Patch(data)
    p.source("In 1", "LFO", "out")
    p.dest("Out 1", "Filter", "cutoff CV in")
    p.note("Level 1", "Level 1", "sets the depth")
    ...
```

Jacks are named as on the panel: `In 1`, `Out 1`, `In 2` and `Out 2`. Sources go on the left, destinations on the right. `note()` puts a caption beside a knob or jack. Pass `color=BLUE` to draw a second signal. To add an example, write a new function, add it to the list in `main()`, and run:

```sh
python3 docs/drawings/make_patch_svgs.py
```
